# GuestHub

GuestHub is a Next.js-based web application designed to manage hotel and accommodation operations. It provides a foundation for user authentication, room management, reservation flow, and an admin dashboard.

## Features

- User authentication and session management
- Room creation, listing, and management
- Reservation creation and tracking
- Admin dashboard structure
- MongoDB-based data models with Mongoose integration
- JWT-based authorization support

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- MongoDB + Mongoose
- JSON Web Token (JWT)
- bcryptjs
